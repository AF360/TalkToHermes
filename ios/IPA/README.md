# TalkToHermes 1.0.4 — unsigned iOS IPA

This IPA is intentionally unsigned and cannot be installed directly as-is on a normal iOS device. It is intended for users to sign with their own Apple identity using a sideloading tool such as AltStore Classic or Sideloadly. No signing certificate, provisioning profile, or developer device list is supplied. Signing, installation, refresh requirements and Apple account limits depend on the user's tooling and account.

Optional unsigned iOS IPA for TalkToHermes 1.0.4 (build 4), supporting iPhone and iPad on iOS 17 or later. Intended for re-signing with your own Apple identity using a sideloading tool such as AltStore Classic or Sideloadly. No developer signing identity or provisioning profile is included. The device build and IPA structure are verified; sideload installation has not yet been tested. 
A separately configured TalkToHermes backend and the user's own connection credentials are still required.
